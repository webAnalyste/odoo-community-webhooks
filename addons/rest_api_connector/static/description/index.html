REST API Connector

API REST JSON pour piloter Odoo depuis n8n, Make, scripts, curl, etc.

Authentification : header X-API-Key: <votre_cle> sur toutes les requêtes.
Clé : Paramètres → Technique → Paramètres système → rest_api_connector.api_key
Base URL : https://odoo.webanalyste.com  •  Content-Type (POST/PUT) : application/json

Exemples curl — Entreprises

Lister les entreprises à Paris

curl -s \
  -H "X-API-Key: VOTRE_CLE" \
  "https://odoo.webanalyste.com/api/v1/companies?city=Paris&limit=20"

Détail (id=42)

curl -s \
  -H "X-API-Key: VOTRE_CLE" \
  "https://odoo.webanalyste.com/api/v1/companies/42"

Créer

curl -s -X POST \
  -H "X-API-Key: VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"name": "Acme SA", "email": "contact@acme.fr", "phone": "0600000000", "city": "Paris", "zip": "75001", "country_id": 75, "vat": "FR12345678901"}' \
  "https://odoo.webanalyste.com/api/v1/companies"

Modifier (id=42)

curl -s -X PUT \
  -H "X-API-Key: VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"phone": "0600000001", "website": "https://acme.fr"}' \
  "https://odoo.webanalyste.com/api/v1/companies/42"

Archiver (id=42)

curl -s -X DELETE \
  -H "X-API-Key: VOTRE_CLE" \
  "https://odoo.webanalyste.com/api/v1/companies/42"

Exemples curl — Opportunités CRM

Lister les opportunités depuis le 1er janvier 2026

curl -s \
  -H "X-API-Key: VOTRE_CLE" \
  "https://odoo.webanalyste.com/api/v1/crm/leads?created_after=2026-01-01&limit=50"

Créer une opportunité formation

curl -s -X POST \
  -H "X-API-Key: VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"name": "Formation Python - Acme SA", "partner_id": 42, "stage_id": 1, "expected_revenue": 2500.00, "x_participants": 8, "x_date_debut": "2026-09-01", "x_date_fin": "2026-09-05", "x_nb_heures": 35}' \
  "https://odoo.webanalyste.com/api/v1/crm/leads"

Modifier le stage et la probabilité (id=99)

curl -s -X PUT \
  -H "X-API-Key: VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"stage_id": 3, "probability": 75}' \
  "https://odoo.webanalyste.com/api/v1/crm/leads/99"

Archiver (id=99)

curl -s -X DELETE \
  -H "X-API-Key: VOTRE_CLE" \
  "https://odoo.webanalyste.com/api/v1/crm/leads/99"
